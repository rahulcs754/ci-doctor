# Research notes (Oct 2026)

- Public GitHub Actions minutes reached 11.5 billion, up 35% in a year; merged PRs up 29%. Source: GitHub Octoverse 2025.
- AI coding agents open more PRs and push more often, so CI bills grow. Vendor estimate: a 20-person team going from $640 to $2,880 a month. Source: https://tenki.cloud/blog/hidden-ci-tax-ai-coding-agents (vendor, treat as rough).
- Cloud waste rose to 29% of spend. Source: https://tech-insider.org/cloud-waste-29-percent-finops-2026/ (Flexera 2026).

## Competitors
- Blacksmith, Depot, Tenki: sell faster or cheaper runners; analytics are a hook to sell runners.
- Datadog CI Visibility: broad, team-priced.
- GitHub's own usage page: shows minutes, gives no fixes.

**Gap:** a free, open-source tool that explains the waste and the failure, and opens the fix PR itself, with no runner to buy.
